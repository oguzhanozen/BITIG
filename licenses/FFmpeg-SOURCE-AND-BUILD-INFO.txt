FFmpeg 9.0 Essentials Build — Source and Build Information
===========================================================

BITIG for Windows bundles unmodified ffmpeg.exe and ffprobe.exe files from the
Gyan FFmpeg 9.0 essentials build. The binaries are separate programs invoked
as subprocesses. They are licensed under GNU GPL version 3; the complete GPLv3
text is included as FFmpeg-GPLv3.txt.

Binary release and build provenance:
https://github.com/GyanD/codexffmpeg/releases/tag/9.0

Exact FFmpeg source revision identified by the binary distributor:
https://github.com/FFmpeg/FFmpeg/commit/d32b387f2b

Downloadable source archive for that revision:
https://github.com/FFmpeg/FFmpeg/archive/d32b387f2b.zip

Build provider information, dependency list, and current build documentation:
https://www.gyan.dev/ffmpeg/builds/

The distributed files report:

ffmpeg version 9.0-essentials_build-www.gyan.dev
built with gcc 16.1.0 (Rev2, Built by MSYS2 project)
