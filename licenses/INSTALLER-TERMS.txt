PART I - BITIG Terms of Use
==========================

1. Purpose and permitted use

BITIG provides media analysis, downloading, local playback, and local library
management for content you have the right to download and store. A local
yt-dlp executable analyzes media URLs and downloads selected media. FFmpeg
and ffprobe support merging, conversion, and media validation. Saved media
can also be exported as a local file copy.

Use these features consistently with applicable copyright law, any required
permissions, and lawful exceptions. A working download link does not itself
establish permission. Observe third-party platform terms that apply to your
use. BITIG does not provide DRM, paywall, or authentication bypass features.

2. Local features and online operations

The saved library can be browsed, organized, and played locally while offline,
subject to the available files and supported formats. Analyzing online media
and downloading it require access to the relevant third-party services.
Missing tool installation and tool update checks or downloads also require
internet access. Part III explains the associated storage and connections.

3. Required media tools and online setup

The Online Installer does not embed yt-dlp, FFmpeg, or ffprobe in
setup.exe. These tools are required for BITIG's core analysis, downloading,
and media processing features; they are independent open-source projects.

Setup first reuses existing verified BITIG-managed tools, without a network
request when a valid set is available. Otherwise it downloads yt-dlp from
the yt-dlp project's GitHub Releases and the FFmpeg essentials build from
GyanD/codexffmpeg GitHub Releases. FFmpeg and ffprobe are taken together from
the same archive. GyanD is the selected Windows binary distributor, not the
FFmpeg development project.

Downloads use HTTPS and SHA-256 verification, with size and archive safety
checks before atomic installation. Setup cannot complete successfully if
the required tools cannot be obtained and verified. Independent yt-dlp or
FFmpeg installations on the system PATH are not used by this installer.
Previously verified BITIG tool installations are retained for safety because
another running BITIG process may still use them; disk use can grow over time.

4. Optional automatic media tool updates

Automatic media tool updates are optional and off by default. Accepting these
Terms does not authorize automatic updates. The installer update choice is
separate, and the preference can later be changed in About & Tools. An existing
saved enabled/disabled application preference takes priority over the
installer preference. Manual tool checks and installation remain available.
Newly installed updates require restarting BITIG before they are used.
This feature updates media tools, not the BITIG application itself.

5. Technical limitations, warranty, and liability

PART III - Local Data Storage and Network Connections
====================================================

This part is informational. It is not contractual consent or general explicit
consent under Turkey's Personal Data Protection Law (KVKK). Installer
acceptance and the optional automatic-update preference are separate matters.

BITIG is local-first. Its SQLite library.db and managed media are stored under
the OS-resolved application local data directory (AppLocalData). It uses
media/ for saved media, thumbnails/ for artwork, temp/ for work in progress,
tools/ for managed media tools, and logs/ for local diagnostic logs. The
installer update preference is stored in installer-preferences.json there.
Interface preferences, including the application tool-update choice, are
stored in WebView2 localStorage.

Media URLs and metadata can appear in local records. URL storage filtering
removes fragments and attempts to remove specified sensitive query parameters,
such as tokens and signatures. It does not guarantee removal of all personal
or confidential information from URLs or metadata.

BITIG contacts GitHub for required tool provisioning when verified managed
tools are unavailable, and for tool checks/downloads initiated by you or
authorized through the optional automatic-update preference. Media analysis
or downloading initiated by you connects the local media tool to third-party
media platforms and associated content services. Those services can see your
IP address and normal connection/request information, including the media
resource requested. Their data processing is governed by their own practices.

The application source examined for this document contains no telemetry or
analytics feature and no developer-operated server for collecting your media
data. This describes BITIG's application code, not a guarantee about every
third-party tool, service, Windows component, or network connection. Local
storage and URL filtering are not absolute privacy or security guarantees.
