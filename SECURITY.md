# Security policy

## Supported versions

Security fixes are provided for the latest BITIG `0.1.x` release. Older builds
may be asked to upgrade before a report is investigated.

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub
Security Advisory **Report a vulnerability** form. Do not include exploit
details, credentials, private media URLs, or personal data in a public issue.

Include the affected BITIG version, Windows version, reproduction steps, impact,
and any relevant logs after removing tokens, signatures, cookies, credentials,
and private URLs. You should receive an acknowledgement within seven days.

BITIG does not accept requests to add DRM, paywall, authentication, or other
access-control bypasses. Reports involving such bypasses may be closed as out
of scope unless they demonstrate a vulnerability in BITIG itself.
