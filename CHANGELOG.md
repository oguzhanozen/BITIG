# Changelog

All notable changes to BITIG are documented in this file.

## [0.1.0] - 2026-08-09

### Added

- Local-first Tauri 2 media library with SQLite-backed folders and metadata.
- URL analysis and managed video/audio downloads through bundled yt-dlp and FFmpeg sidecars.
- Batch selection, move, delete, format filters, and card, compact, and list collection views.
- Light/dark appearance modes and selectable color palettes.
- Integrated native-behavior title bar, first-run Quick Tour, and media tool status screen.
- Hash-verified Windows x64 sidecar manifest, license notices, and NSIS installer packaging.
